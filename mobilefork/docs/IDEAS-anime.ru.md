# Идеи: Krita Mobile для сольной аниме-анимации

Список идей для следующих этапов. Ничего из этого не реализовано в текущей
работе (кроме отмеченного), всё рассчитано на телефон и на одного автора,
который делает короткие аниме-ролики целиком сам. Для каждой идеи указано,
откуда она (Clip Studio Paint EX, Toon Boom Harmony, OpenToonz, Blender Grease
Pencil) и что уже есть в Krita, на что можно опереться.

## 1. Раскадровка и планирование

1. **Раскадровка → таймлайн одним жестом.** Docker «Storyboard» уже есть в Krita
   (и доступен в панели «Анимация»). Идея: кнопка «Сделать сцены из раскадровки» —
   каждая панель становится диапазоном кадров с длительностью из раскадровки
   (CSP EX: storyboard → timeline; Toon Boom Storyboard Pro).
2. **Аниматик со звуком.** Krita умеет звуковую дорожку; добавить в телефонный
   таймлайн быструю подрезку звука и метки реплик (OpenToonz: Sound column + lip-sync).
3. **Шаблон «аниме-шот»**: пресет нового документа 1920×1080 / 24 к/с с готовыми
   слоями «Layout / Key / Inbetween / Clean / Color / BG» (CSP: шаблоны анимации).

## 2. Ключи, фазовки и тайминг

4. **Тайм-шит (X-sheet / dope sheet) на телефоне.** Вертикальная таблица кадров ×
   слоёв, как в Toon Boom Xsheet и OpenToonz Xsheet: для аниме-тайминга «на двойках /
   тройках» удобнее, чем горизонтальный таймлайн. Можно построить на модели
   таймлайна Krita (KisTimeBasedItemModel).
5. **«Ключ / фазовка / промежуточный» как метки кадров.** У Krita есть цветные
   метки кадров; дать им смысл (key, extreme, breakdown, inbetween) с фильтром и
   переходом между ключами (CSP: метки; Harmony: drawing types).
6. **Таймшит-заметки и «тайминговые лесенки»** (spacing charts) поверх кадра — как
   слой-аннотация, который не попадает в рендер (Toon Boom: Timing Chart).
7. **Быстрая смена удержания кадра (hold) свайпом по ячейке** — «растянуть ключ на
   2/3/4 кадра» (OpenToonz: «Increase step»).

## 3. Рисование промежуточных кадров

8. **Улучшенный onion skin для фазовки**: показывать только предыдущий и следующий
   *ключ* (а не соседние кадры), с цветами «до/после» — Krita уже имеет onion
   skins; нужен режим «по меткам ключей» (CSP light table, Harmony light table).
9. **Световой стол (light table) с поворотом/сдвигом листа** — «перелистывание»
   (flipping/rolling) пальцем, как у аниматоров на бумаге (CSP EX: light table;
   Harmony: rolling).
10. **Вспомогательные промежуточные кадры для векторных контуров** — морфинг
    векторных форм между ключами (Harmony: shape tweening; Blender Grease Pencil:
    interpolate tool). В Krita векторные слои уже есть, нужен инструмент
    интерполяции.
11. **Перенос линий (inbetween helper) для растровых линий**: отображение
    «средней линии» между двумя ключами как подложки (Grease Pencil interpolate).

## 4. Чистовая линия и заливка

12. **Заливка по линиям другого слоя с закрытием зазоров** — у Krita есть
    «заливка по референсу» и маска раскраски (Colorize Mask); собрать это в один
    режим «аниме-заливка: линия на слое Line, цвет на слое Color» (CSP: reference
    layer + close gap; OpenToonz: autoclose).
13. **Цвет контура (color trace lines)**: линии теней/бликов другого цвета,
    которые не попадают в итоговый контур (OpenToonz/Harmony: color trace).
14. **Палитра персонажа с именованными цветами и заменой по всей сцене** (Harmony:
    palette per character, OpenToonz: style replace). Krita: палитры уже есть,
    нужна глобальная замена цвета на всех кадрах.

## 5. Камера и композитинг

15. **2D-камера с ключами** (pan/zoom/rotate на весь кадр) — сейчас Krita
    анимирует трансформ-маски слоёв; камера как отдельный объект (CSP EX: camera
    layer; OpenToonz: camera column).
16. **Слои-ячейки с параллаксом** (multiplane) — Toon Boom/OpenToonz.
17. **Шаблоны эффектов аниме**: свечение, блики, «speed lines», размытие движения
    как готовые фильтр-маски с анимируемыми параметрами (Krita уже умеет
    анимировать параметры фильтров).

## 6. Удобство на телефоне

18. **Жест «прокрутка кадров двумя пальцами» по краю экрана** — перелистывание
    вперёд/назад без открытия таймлайна (сейчас: кнопки таймлайна в панели).
19. **Мини-таймлайн полоской над нижней панелью** для режима анимации, с
    кнопками «кадр назад/вперёд/новый пустой кадр/копия кадра».
20. **Быстрый предпросмотр на пониженном разрешении** (кэш анимации уже
    ограничен 1920 px на телефоне) и экспорт в MP4/GIF в один тап с пресетами
    для соцсетей.
21. **Автосохранение версий сцены** (инкрементальные версии уже есть в Krita —
    вынести на видное место в телефонном интерфейсе).

## 7. Звук и липсинк

22. **Липсинк по фонемам** (OpenToonz: Magpie import / auto lip-sync; Harmony:
    lip-sync detection): метки фонем на звуковой дорожке и подстановка рисунков рта.

## Порядок, который кажется разумным

1 → 5 → 8 → 18/19 → 4 → 12 → 15 → остальное: сначала то, что опирается на уже
существующие механизмы Krita (раскадровка, метки кадров, onion skin, маска
раскраски), затем новые сущности (камера, X-sheet).
